# Glosario (EJEMPLO)

> Nota: Documento de (EJEMPLO) para pruebas y demostración de Nexo.

- **BFF** (Backend For Frontend): capa que adapta los servicios para un frontend.
- **MFE** (Microfrontend): aplicación de frontend que se despliega por separado.
