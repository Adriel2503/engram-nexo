# Componentes del sistema de diseño (EJEMPLO)

> Nota: Documento de (EJEMPLO) para pruebas y demostración de Nexo.

Los componentes viven en el paquete `@demo/ui`. No se crean componentes nuevos si ya existe uno equivalente.

## Botones

Hay tres variantes: primario, secundario y de texto. Solo un botón primario por pantalla.

## Tablas de datos

Las tablas usan paginación del lado del servidor a partir de 50 filas.
